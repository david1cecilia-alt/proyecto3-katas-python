# Katas de Python

40 ejercicios de Python del **1º de Ciberseguridad**. Cada archivo `KatasEN.py` resuelve un problema, casi siempre con una función comentada.

## Qué se practica

- Manipulación de cadenas (frecuencia de letras, anagramas…)
- Listas, diccionarios y comprensiones
- Funciones, condicionales y bucles
- Lógica de resolución de problemas

## Cómo ejecutarlos

Requiere Python 3.

```bash
python KatasE1.py
```
